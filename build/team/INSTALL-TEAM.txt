Parsons NWC Federator, how to install it

This is an add-in for Navisworks Manage 2025. It installs for you alone, in your own Windows
profile, and needs no admin rights. VERSION.txt in this folder says which version this zip holds.


To install

1. Close Navisworks Manage 2025.
2. Right click the zip and choose Extract All, then open the folder that makes. A file opened
   inside the zip without extracting it does not work.
3. Double click "Install Parsons NWC Federator.cmd". A black window opens. If Windows asks
   whether to run it, choose Run.
4. Read the last line in the window, then press any key to close it.
     DONE:     it worked. The line says which version is installed, where, and where the
               version you had before is kept.
     REFUSED:  nothing was changed. The line says why and what to do, most often close
               Navisworks and double click the file again.
     FAILED:   it stopped part way. The line says where each version is and what to do.
5. Start Navisworks Manage 2025 and look on the Tool Add-ins tab for Parsons NWC Federator.

Installing a newer zip the same way replaces the add-in and keeps the version you had before.
Only one earlier version is kept, so each install replaces the one kept before it.


To go back to the version you had before

1. Close Navisworks Manage 2025.
2. Double click "Put back the previous version.cmd" in the folder of any extracted zip.
3. Read the last line. DONE: says which version is back. The version you had installed is not
   kept, so to have it again, run the install in the folder of its zip.


If a line says FAILED, or you are not sure, take a screenshot of the whole window and send it
to whoever sent you this zip.
