# linked DWG files, because on these NWCs a node above the geometry carries a
# property called Category whose value is its own name. They are in the list because
# the tool reads them as a category, and a list that left them out would not be what
# was measured. A set asking for one of them by equals matches it, which is right,
# because the model does carry it.
#
# IT IS ONE FOLDER OF THE PROJECT. C02 is ten buildings. A category another building
# carries and these do not is reported as one nobody has until the walk is run over

# tell. Re-measure by running the probe's walk mode over more NWFs and replacing the
# lines below.

# IT IS A FILE AND NOT A LIST IN A METHOD because it is read off the CLIENT'S MODELS

# reason: the Navisworks units enum never changes.

# trimmed. A line beginning # is a comment. A blank line is ignored. Nothing else.
