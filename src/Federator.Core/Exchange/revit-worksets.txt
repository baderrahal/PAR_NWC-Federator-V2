# WHAT IT IS FOR. The client's matrix asks for a workset called ME-DUCTWORK and the C02
# models write ME-Ductwork, and a search condition compares a value CASE SENSITIVELY unless
# IgnoreDisplayStringValueCase is set, which nothing sets. So a set asking one spelling
# finds nothing in the models writing another. MatrixCorrections asks every spelling of a
# workset that this file and the list beside the picked XML hold between them, as Or groups,
# where there are two or more, Q102, and the one there is where there is one, Q68, and these
# two are where the spellings come from. THE TOOL NEVER INVENTS ONE.
#
# WHY IT IS NOT AN IGNORE CASE FLAG. Bader refused that on 2026-09-20 and the reason
# is in this list twice over: AR-EXTERIOR against AR-INTERIOR, and ST-SUB against
# ST-SUP, are two pairs of REAL worksets one and two letters apart. A flag that
# forgave case would not have merged those, but a rule that forgave more would, and
# the line between the two is not one this tool is allowed to draw.
#
# FIVE PAIRS IN HERE DISAGREE WITH EACH OTHER AND ONLY THREE ARE TYPOS:
#   EL-Lightining Protection  against  EL-Lightning Protection   a typo
#   EV-Ccctv system           against  EV-Cctv System            a typo
#   PL-Drainage equipmen      against  PL-Drainage equipment     a truncation
#   AR-EXTERIOR               against  AR-INTERIOR               two real worksets
#   ST-SUB                    against  ST-SUP                    two real worksets
# Nothing here is merged. The export check names the pairs and a person fixes the
# models, because a tool that absorbs a typo silently means nobody ever fixes it.
#
# A PERSON HAS DECIDED ABOUT TWO OF THE FIVE PAIRS, and the tool reads the decision
# rather than guessing again every run. A pair written as "not-a-typo: A | B" is two
# DIFFERENT worksets that happen to be a letter or two apart, so the export check counts
# it and does not name it. The other three are left unmarked and are named every run,
# because nobody has fixed the models yet and a tool that stops mentioning a typo is a
# tool nobody fixes anything because of.

not-a-typo: ST-SUB | ST-SUP
