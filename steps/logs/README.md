# logs

Bader drops run logs here after a local run.

1. Run the tool on the local machine
2. Find the log in `%LOCALAPPDATA%\ParsonsNwcFederator\logs`
3. Copy it into this folder
4. Name it with the date and the group, like `2026-09-08-1C07BC.log`
5. Commit and push

Newest first. The worker reads them and writes findings to `steps/log.md`.
