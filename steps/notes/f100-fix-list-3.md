THE LEAD'S DECISIONS:

E1. NOTHING IS SENT BEFORE ADOPTION. Before a Roamer is adopted the watchdog reads only what needs no message sent into another process: top level window handles, their class names with GetClassName and their captions with GetWindowText. No WM_GETTEXT, no SendMessageTimeout, into any window of a process that is not adopted. After adoption, the adopted Roamer's windows are read as now. (Reviewer 13, breaker 3.)

E2. A HAND STARTED NAVISWORKS IS NEVER COUNTED AS A START. The "exactly one new Roamer" test counts only new Roamers whose command line holds the word embedding. A new Roamer whose command line does not is a Navisworks someone started by hand: the result names it as that, it is left alone, it is never written to unproved-starts.txt, and it rules out the put back under D2 because another Navisworks ran. A new Roamer whose command line cannot be read counts as a possible start: it rules out adoption when it is the only one, and it is written to the file. (Breaker 1.)

E3. EVERY START THE PROBE CANNOT PROVE, AND ITS OWN THAT WILL NOT DIE, IS RECORDED. Write to unproved-starts.txt: every new Roamer holding embedding that is not adopted and is still running at the deadline or at the end, whether its start time was read or not, and the adopted Roamer if it is still running after every close path. A Roamer whose start time never read is written with its pid, the word Roamer and the time it was first seen. Step 2 refuses while a pid on a line with no start time runs as a process named Roamer. Start ticks are UTC everywhere they are written or compared. (Reviewer 5 and 17, breaker 2 and 4.)

E4. THE PUT BACK NEEDS A WATCHDOG RECORD AND A LAST CHECK AT THE WRITE. D2's "no other Navisworks ran" is proved only when the watchdog ran: passes above zero, no watchdog error line, nothing in $wps.Streams.Error, and no pass that failed before its process loop. Otherwise nothing is put back and the result says why. Immediately before each registry write and each file copy, the Roamers are listed again, and any Roamer at all stops every write that follows. Before SetValue, DeleteValue, CreateSubKey or DeleteSubKeyTree the value or key is read again and written only if it still reads what the compare read. A value delete is counted only when a value was deleted. (Reviewer 1, 2 and 14.)

E5. THE BACKUP MUST EXIST BEFORE THE START. The reg.exe export must exit 0 and leave a file that is not empty, or the probe stops before the constructor. The same for the copy of the settings files. (Reviewer 4.)

E6. THE DEADLINE PATH IS SAFE AND SAYS WHAT IT LEAVES. Refuse to run when either deadline is below 60 seconds.
